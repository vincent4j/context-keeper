# 继续上次进度

先指定唯一项目记录目录并预览：

```bash
python3 <skill-dir>/scripts/context_keeper_probe.py resume \
  --root <repo> --store-dir <项目记录目录> --query '<当前任务关键词>'
```

向用户展示目录、检索词和读取上限，取得明确确认后，在同一命令加 `--approved --approval-ticket <预览凭据>`。预览凭据由 Agent 处理，用户无需复制；变更范围要重新预览确认。确认后默认输出：

- 最近 3 份工作日志的短摘要。
- `memory-keeper.md` 中最多 5 条与当前任务相关的未完成事项。
- 最多 5 条相关经验；指定类型时优先同类型 3 条，再补其他类型 2 条。

需要问题和经验细节时加 `--details`；用户点名具体记录时才读取对应正文小段。不要因为“继续”默认展开完整日志、plans、全部 memory 或全部 evolution。

工作日志缺少快速摘要时，脚本只做有限提取并明确标注不完整。不要把有限提取包装成完整结论；关键判断仍需打开原记录。

续接输出要区分：

- 已完成事实。
- 当前未完成事项。
- 历史建议或旧的“下一步”。
- 当前会话是否已有执行授权。

未完成事项应包含触发条件、完成条件和证据位置。历史下一步不能自动视为当前授权。用户点名某个问题或准备重复路线时，再运行 `search` 查相关经验；同一问题本轮不重复检索。

有当前关键词时优先补充 evolution 中的有效经验，与历史时间线共用五条上限。已完成或已取消的事项不再作为待办显示。

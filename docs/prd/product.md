# 产品与工作流 PRD

## 目标与用户价值

Context Keeper 为编程 Agent 提供项目记忆：跨会话续接进度、追溯历史事实、复用有依据的经验。以 Markdown、有限检索和宿主 Agent 的判断工作，保持独立运行，不依赖 PRD Distill 或外部记忆服务。

## 用户入口

| 入口 | 用户目标 | 行为与完成标准 |
| --- | --- | --- |
| 保存 | 记录需求、进度与未完成事项 | 日志追加事实，更新当前主题与待办，有长期价值时整理经验，读回并校验 |
| 继续 | 接着完成已有工作 | 先相关当前主题、约束和待办，再按需读来源与经验，定点核验当前环境 |
| 查找 | 核对以前发生过什么或如何处理类似问题 | 限量定位、展开最相关依据，区分原文、摘要、推断和当前适用性 |

只调用 Skill 而未说明动作时展示保存、继续、查找三个选项；已说明动作直接路由。

## 自动触发与授权

- 属于项目会话、已有获授权记录库、允许写入且有未记录事实时，在阶段成果、明确技术选择、影响后续的失败或放弃路线、用户纠正、新证据改变认识、暂停或交接等自然节点保存。
- 无项目聊天默认不查状态、不建库、不保存、不询问建库。cwd、临时目录或讨论仓库不单独证明项目归属。首次建库位置需用户确认。
- 用户提及以前或重复问题、记忆冲突、失败重试或换路线且依据不足、推翻旧决定但原依据缺失时检索。普通新任务、常规实现和文字修改不额外检索。
- 只读要求优先；历史命令、计划、下一步不构成当前授权。保存、提交、推送、部署与跨项目提升分别遵守用户授权。
- 不保存凭据和无关隐私。发现旧结构先经过批准迁移，不绕过门禁读取。

## 写入前经验对照

准备新建或修订经验时，先提炼主题、对象、结论、证据和适用范围，运行 `search --for-write --query '<主题和对象>'`。仅查询配置记录库内的项目经验，默认最多三条，读回最相关的一至两份及必要来源。待验证、已替代条目仅作对照，不输出为当前执行建议；已替代条目沿替代链接核对当前认识。

相同事实无变更；独立验证补原编号；范围过宽修范围；范围内反证降为待验证并暂停采用；验证了有效替代则维护替代关系；独立新主题才新建编号。有限零命中不证明没有旧经验，截断须说明。语义判断与写入由 Agent 在既有保存节点完成，命令本身只读。

## 安装与卸载

支持 Codex、Claude Code、WorkBuddy、ZCode、DeepSeek Harness、OpenCode 的入口配置。macOS/Linux 通过目录符号链接、Windows 通过目录联接加载同一份源码；入口配置与真实宿主验证分开报告，Windows 已验证范围见 [验收 PRD](acceptance.md)。源码是唯一可编辑来源，安装器校验归属，拒绝覆盖不明同名目录。首次入口补齐先只读预览，确认后写入；未确认可继续原操作。重复安装保持幂等，受控块外内容不变。

项目级 Codex、ZCode、DeepSeek Harness 和 OpenCode 共用根 AGENTS.md 区块；部分 Skill 路径也共用。卸载前完整检查所有目标，共享 Skill 入口阻断时列出路径和可能共用的其他宿主，明确尚未删除；按配置可能共用不代表客户端实际安装或运行。预览通过 `kept_shared_rule_files` 列出将保留的共享规则文件，执行使用同一判断，不扩大用户指定范围。

## 非目标与待定范围

不建立后台监听、逐消息 hooks、向量数据库、模型训练、日志事务或强制追加存储系统。操作标签与动作前经验匹配暂缓。写入前对照不保证发现仅留在日志、尚未进入当前摘要或经验的新证据；续接补漏单独验收。
